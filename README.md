# Beyond Words — Public Website

The public-facing landing page for the Beyond Words product concept.

## Contents

- `index.html` — responsive static landing page
- `assets/beyond-words-mark.png` — logo mark

## Preview locally

Open `index.html` in a browser, or run:

```bash
python3 -m http.server 8000
```

Then visit http://localhost:8000.

## Publish with GitHub Pages

1. Create a GitHub repository named `beyond-words`.
2. Upload the contents of this folder to the repository root (so `index.html` is at the root).
3. Open **Settings → Pages**.
4. Choose **Deploy from a branch**.
5. Select branch `main` and folder `/(root)`, then save.
6. The site will be published at `https://YOUR-USERNAME.github.io/beyond-words/`.

## Before publishing

Replace the placeholder `hello@example.com` in `index.html` with a real monitored contact address, or change the early-access CTA.

The website presents an early product concept. Product mockups are illustrative and should not be represented as screenshots of a released application.
